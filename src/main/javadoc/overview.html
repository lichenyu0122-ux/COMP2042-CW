COMP2042 Snake is a JavaFX game with three selectable levels. Each level file sets the board size, walls, target and starting speed; the difficulty choice adjusts that speed.

The controller reads menu and keyboard input, updates the model, and tells the view when to redraw. The view reads game state from the model to draw the board and score. The model handles movement, collisions, coins and timed effects without JavaFX.

See Design.pdf for the class relationships.
